# WSL2 极客指南：从零搭建 Ubuntu + XFCE 远程桌面与中文输入法（避坑全记录）

## 📖 前言

在 Windows 上体验完整的 Linux 图形界面，**WSL2 (Windows Subsystem for Linux) + XRDP + 轻量级桌面环境** 是目前最完美的方案之一。它不仅占用资源少，还能与 Windows 无缝联动。

然而，在实际操作中，你可能会遇到诸如 `0x80370114` 报错、黑屏闪退、环境变量冲突、输入法无法切出等一系列“坑”。本文将基于一次真实的折腾经历，完整记录从安装 WSL 到完美运行中文桌面环境的全过程，帮你避开 99% 的雷区。

---

## 🛠️ 第一阶段：WSL 基础环境与坑点排查

### 1. 开启 Windows 虚拟化功能

以**管理员身份**打开 PowerShell，运行以下命令：

```powershell
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
```

> ⚠️ **避坑提示**：执行完后务必**重启电脑**。如果你遇到了 `0x80370114` 错误，或者提示 `net start vmcompute 服务名无效`，通常是因为底层组件没激活，请尝试通过“启用或关闭 Windows 功能”界面手动勾选“虚拟机平台”和“适用于 Linux 的 Windows 子系统”并再次重启。

### 2. 安装 Ubuntu

在 Microsoft Store 搜索并安装 Ubuntu。安装完成后打开，设置你的 **UNIX 用户名** 和 **密码**（输入密码时屏幕不显示是正常现象）。

---

## ⚙️ 第二阶段：系统初始化与源替换

为了后续下载桌面环境不卡顿，首先更换国内软件源（以清华源为例）。在 Ubuntu 终端中执行：

```bash
# 备份原有源
sudo cp /etc/apt/sources.list /etc/apt/sources.list.bak

# 替换为清华源
sudo sed -i 's|http://.*archive.ubuntu.com|https://mirrors.tuna.tsinghua.edu.cn|g' /etc/apt/sources.list

# 更新软件列表
sudo apt update
```

---

## 🖥️ 第三阶段：安装 XFCE 桌面与远程服务

> 🚫 **避雷警告**：**千万不要安装 `ubuntu-desktop`！** 它自带的 GNOME 桌面非常臃肿，且在 WSL 下极易因为依赖问题导致黑屏或卡死。推荐使用轻量级的 **XFCE**。

1. **安装核心组件**：
   ```bash
   sudo apt install xorg xfce4 xfce4-goodies xrdp -y
   ```

2. **修改 XRDP 默认端口**（防止与 Windows 自带的远程桌面 3389 端口冲突）：
   ```bash
   sudo sed -i 's/port=3389/port=3390/g' /etc/xrdp/xrdp.ini
   ```

3. **指定 XFCE 为默认会话**：
   ```bash
   echo "xfce4-session" > ~/.xsession
   ```

4. **重启 XRDP 服务**：
   ```bash
   sudo service xrdp restart
   ```

此时，在 Windows 搜索“远程桌面连接”，输入 `localhost:3390`，即可尝试连接。

---

## 🚑 第四阶段：黑屏与报错的“终极修复”

如果你连上桌面后遇到了**纯黑屏**、只有鼠标、或者报错 `Unable to start notification daemon... Wayland compositor...`，这是因为 WSLg 的 Wayland 环境变量干扰了 XRDP 的 X11 会话。

我们需要修改 XRDP 的启动脚本，**强制使用 X11 并清理冲突变量**。使用 `nano` 编辑器打开文件：

```bash
sudo nano /etc/xrdp/startwm.sh
```

**清空里面原有的所有内容**，将下面这段经过实战检验的终极代码复制进去：

```bash
#!/bin/sh

# 1. 清理 WSLg 冲突变量（解决黑屏和通知弹窗报错）
unset DBUS_SESSION_BUS_ADDRESS
unset XDG_RUNTIME_DIR
unset WAYLAND_DISPLAY

# 2. 强制使用 X11 后端
export GDK_BACKEND=x11
export QT_QPA_PLATFORM=xcb

# 3. 配置输入法环境变量
export GTK_IM_MODULE=fcitx
export QT_IM_MODULE=fcitx
export XMODIFIERS=@im=fcitx

# 4. 加载环境变量
if test -r /etc/profile; then
    . /etc/profile
fi
if test -r ~/.profile; then
    . ~/.profile
fi

# 5. 启动 D-Bus 会话和 Fcitx（解决输入法框架无法连接 D-Bus 的问题）
eval $(dbus-launch --sh-syntax)
fcitx &

# 6. 启动 XFCE 桌面
startxfce4
```

保存退出（`Ctrl+O` 回车，`Ctrl+X`），并重启服务：

```bash
sudo service xrdp restart
```

## 🇨🇳 第五阶段：中文环境与输入法完美配置

在终端中安装中文包、字体和 Fcitx 输入法：

```bash
sudo apt update
sudo apt install language-pack-zh-hans fonts-wqy-microhei fonts-wqy-zenhei fcitx fcitx-pinyin fcitx-config-gtk dbus-x11 -y
```

### 1. 设置默认语言

```bash
sudo dpkg-reconfigure locales
```
使用方向键找到 `zh_CN.UTF-8 UTF-8`，按**空格键**打星号，Tab 键切换到 OK。在下一个界面选择 `zh_CN.UTF-8` 作为默认语言。完成后重启。

### 2. 设置输入法全局环境变量

为了防止输入法只在终端生效，在图形界面失效，需要配置 `/etc/environment`：

```bash
sudo nano /etc/environment
```

在文件末尾添加：

```text
GTK_IM_MODULE=fcitx
QT_IM_MODULE=fcitx
XMODIFIERS=@im=fcitx
```

### 3. 设置系统默认输入法框架

```bash
im-config -n fcitx
```

---

## 🔗 第六阶段：连接与日常使用贴士

1. 在 Windows 中打开**远程桌面连接**，输入 `localhost:3390`。
2. 输入你的 Ubuntu 用户名和密码。
3. 打开任意文本编辑器，按下 **`Ctrl + 空格`**，即可看到输入法候选框，尽情输入中文！

> 💡 **日常使用必看：**
> 每次重启 Windows 电脑后，WSL 不会自动启动后台服务。你需要先在 Windows 中打开 Ubuntu 终端，执行 `sudo service xrdp restart`，然后再去连远程桌面。你也可以写一个 `.bat` 脚本放在桌面，一键启动 WSL 和 XRDP 服务。

## 🎉 总结

通过以上步骤，你就能在 Windows 上拥有一套独立、流畅、支持中文输入的 Linux 桌面环境了。相比传统的虚拟机，WSL2 + XRDP 的方案在性能损耗和系统融合度上有着无可比拟的优势。如果在配置过程中遇到其他问题，欢迎在评论区留言交流！
